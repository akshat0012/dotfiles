# BASE Rice (Arch + BSPWM)

![preview](/previews/s_1770765974.png)

## :snowflake: My Setup

- **WM :** BSPWM
- **Terminal :** alacritty
- **Shell :** bash
- **App launcher :** dmenu
- **File manager :** lf

## :wrench: Installation

```
Clone this arch-bspwm-base branch

./install.sh
./setup.sh

```

## :black_square_button: Keybinds

| Keys | Action |
|----|----|
| `Super + Shift + S` | Take screenshot (saved as PNG with timestamp) |
| `XF86AudioMute` | Toggle system mute |
| `Super + Return` | Launch terminal (Alacritty) |
| `Super + B` | Launch browser (Firefox) |
| `Super + Space` | Program launcher (dmenu) |
| `Super + Escape` | Reload sxhkd configuration |
| `Super + Alt + Q` | Quit bspwm |
| `Super + Alt + R` | Restart bspwm |
| `Super + Shift + Q` | Close focused window |
| `Super + H` | Toggle hidden layout |
| `Super + T` | Set window to tiled |
| `Super + Shift + T` | Set window to pseudo-tiled |
| `Super + S` | Set window to floating |
| `Super + F` | Set window to fullscreen |
| `Super + Ctrl + M` | Mark window |
| `Super + Ctrl + X` | Lock window |
| `Super + Ctrl + Y` | Sticky window |
| `Super + Ctrl + Z` | Private window |
| `Ctrl + Alt + Shift + ←` | Swap window west |
| `Ctrl + Alt + Shift + ↓` | Swap window south |
| `Ctrl + Alt + Shift + ↑` | Swap window north |
| `Ctrl + Alt + Shift + →` | Swap window east |
| `Ctrl + Alt + ←` | Focus window west |
| `Ctrl + Alt + ↓` | Focus window south |
| `Ctrl + Alt + ↑` | Focus window north |
| `Ctrl + Alt + →` | Focus window east |
| `Super + ←` | Focus previous desktop |
| `Super + →` | Focus next desktop |
| `Super + Shift + ←` | Send window to previous desktop |
| `Super + Shift + →` | Send window to next desktop |
| `Super + Ctrl + Shift + ←` | Expand window left |
| `Super + Ctrl + Shift + ↓` | Expand window downward |
| `Super + Ctrl + Shift + ↑` | Expand window upward |
| `Super + Ctrl + Shift + →` | Expand window right |
| `Super + Ctrl + ←` | Contract window from right |
| `Super + Ctrl + ↓` | Contract window from top |
| `Super + Ctrl + ↑` | Contract window from bottom |
| `Super + Ctrl + →` | Contract window from left |
| `Super + ←` | Move floating window left |
| `Super + ↓` | Move floating window down |
| `Super + ↑` | Move floating window up |
| `Super + →` | Move floating window right |
